# Rahma's Professional Portfolio

A responsive personal portfolio website focused on **Facility Management**, supported by project management, business analytics and data analytics capabilities.

## Files

- `index.html` — website content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation, project filters and case overview dialogs
- `assets/` — add your approved profile photo, project visuals and CV here

## Before publishing

Update these placeholders in `index.html`:

1. Replace `YOUR.EMAIL@example.com` with your professional email address.
2. Replace the LinkedIn URL `https://www.linkedin.com/` with your profile URL.
3. Review the About, Experience and project descriptions for accuracy.
4. Add only project information, client names, images and results you are authorized to share.
5. Consider adding a PDF CV to `assets/` and linking it from the homepage.

## Publish with GitHub Pages

1. Create a **public** repository named exactly `rahmameysf.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository's root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. After GitHub finishes publishing, visit `https://rahmameysf.github.io`.
